# FCY Tactical Board

1분 이내 축구 경기 영상을 올리고 **유니폼 색으로 팀을 지정**하면, 영상 속 선수 위치를 추적해
평균 포메이션과 반복되는 움직임 패턴을 전술 보드로 보여주는 웹사이트입니다.
서버 없이 브라우저 안에서만 분석하며 영상은 어디로도 전송되지 않습니다.

## 기능

1. **분석 팀 색 선택** — 분석할 팀의 유니폼 색 이름(빨간색, 파란색, 흰색 …)을 고릅니다.
2. **영상 업로드 → 팀 자동 판단** — 60초 이내 영상을 올리면 화면 속 선수들의 유니폼 색을 자동으로 묶어, 고른 색에 해당하는 팀을 분석 팀으로, 반대 팀을 상대 팀으로 판단합니다. 초과 길이는 거부합니다.
3. **평균 포메이션 배치 분석** — 프레임마다 검출한 선수를 역할(포지션)에 배정해 평균 위치를 구하고, 전술 보드 사진(PNG 저장 가능)으로 표시.
4. **움직임 변화** — 반복 패턴 분석과 두 가지 애니메이션
   - 공 위치에 따른 포메이션·움직임 변화 (공이 있는 구역별 평균 배치, 반복 횟수, 반응 일관성, 반응 지연)
   - 상대 선수 움직임에 따른 포메이션·움직임 변화 (상대 블록의 전진·후퇴·좌우 이동에 대한 반응)

## 실행

정적 사이트라 빌드가 필요 없습니다.

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000` 접속. GitHub Pages(Settings → Pages → 브랜치 루트)에 그대로 올릴 수 있습니다.

## 동작 방식

| 단계 | 내용 | 파일 |
| --- | --- | --- |
| 프레임 추출 | 초당 5프레임을 640px 폭으로 추출 | `js/app.js` |
| 인식 | 잔디 색 자동 추정 → 잔디가 아닌 덩어리 검출 → 유니폼 색으로 팀 분류, 공 후보 검출, 카메라 이동 추정 | `js/vision.js` |
| 좌표 변환 | 경기장 네 모서리(조정 가능)로 호모그래피 → 105×68m 좌표 | `js/analysis.js` |
| 분석 | 헝가리안 배정으로 역할 추적, 라인 분할로 포메이션 판정, 공 궤적 추적, 상황별 패턴 집계 | `js/analysis.js` |
| 표시 | 전술 보드 렌더링·애니메이션 | `js/board.js` |

## 정확도에 대해

색 기반 영상 인식이므로 다음 경우 정확도가 떨어집니다.

- 유니폼 색이 잔디·라인(흰색)·상대 팀과 비슷한 경우
- 선수가 매우 작게 보이거나 화질이 낮은 경우, 선수가 많이 겹치는 경우
- **중계 화면 모드**: 실제 거리를 알 수 없어 팀 크기를 표준 값으로 정규화하고, 화면 밖 선수는 계산에서 빠집니다. 경기장 전체가 보이는 고정 카메라 영상이 가장 정확합니다.
- 골키퍼는 유니폼이 달라 보통 검출되지 않으며, 보드에는 기본 위치에 점선 테두리로 표시됩니다.

3단계 미리보기에서 자동 판단 결과와 검출 박스를 확인하세요.

`sample/demo.*` 는 `tools/make-demo.mjs` 로 만든 합성 시뮬레이션 영상(빨간 팀 4-4-2, 파란 팀 4-3-3)입니다.
