# SPOT

전국 유·청소년 축구팀을 찾고 팀 철학을 보여 주는 정적 사이트. 빌드 도구와 의존성 없음. 파일을 그대로 열거나 정적 서버로 띄운다.

공개 주소: https://leeandlee0713.github.io/FCY/spot/ (저장소 전체의 작업 순서는 루트의 `AGENTS.md`)

```bash
python3 -m http.server 8000
```

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 검색 화면. 좌측 필터, 카드 보기, 지도 보기(전국 → 시·도 확대) |
| `team.html` | 팀 페이지. 주소 끝의 `#팀id`로 팀을 고른다. `#팀id-locker`는 팀 라커룸, `#팀id-p숫자`는 선수 라커 |
| `teams.js` | 팀 데이터. 두 화면이 함께 쓴다. 팀 추가는 `TEAMS` 배열에 항목 추가 |
| `geo-kr.js` | 전국 시·도, 시·군·구 경계(통계청 2013년 기준, 단순화). `KR.sido`, `KR.sgg` |
| `*.webp` | 팀 로고, 카드 포스터, 라커룸 배경(가로·세로), 선수 라커 사진(필드·골키퍼) |

## 지켜야 할 것

- 색, 서체, 모서리 값은 각 HTML 맨 위 `:root`의 토큰만 쓴다. 검색 화면과 팀 페이지는 같은 토큰을 쓴다.
- 팀·선수·기사 데이터는 예시다. 실제 자료 없이 새 수치나 인물을 지어내지 않는다.
- 선수가 입력하는 값(프로필, 커리어, 성장일지)은 `team.html`의 `Store`가 맡는다. claude.ai 안에서는 공유 저장소를, 그 밖에서는 브라우저 `localStorage`를 쓴다. 다른 서버에 올리려면 `Store`의 `save`, `saveJournal`, `open`만 바꾸면 된다.
- 사용자가 입력한 글자는 화면에 넣을 때 반드시 `esc()`를 거친다.
- 선수 라커 사진 위의 이름·등번호 위치는 `.j-name`, `.j-num`, `.j-plate`, `.j-short`의 퍼센트 값이다. 사진을 바꾸면 이 값도 다시 맞춘다.
- 수정 후 PC(1440×900)와 모바일(375×740)에서 카드 보기, 지도 보기, 팀 페이지, 팀 라커룸 세 항목, 선수 라커 세 항목을 모두 확인한다.
